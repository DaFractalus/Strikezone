This is a very early and premature version of a game i'm working on called "Strikezone",
generally it's supposed to become a top-down 3D game about adventure and combat but this is the progress i got the last 2 weeks:

Since the game is made without an engine, i used C++, OpenGL and GLFW, which i learned through resources such as learnopengl.com 
It mostly has the code foundations, the most important milestone is creating a UI that includes a Draggable Window with a title and a few buttons to test interactions.
Unfortunately i didn't get to include actual gameplay in it right now but i've worked on it too seperately.

other libraries used: GLM, Freetype, glad, stb_image, stb_vorbis, assimp.
